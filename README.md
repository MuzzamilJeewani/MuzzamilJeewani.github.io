# Student Portfolio

This portfolio follows the structure described in the Effat University Student Portfolio Tutorial.

## Files
- `index.html` — main portfolio page
- `css/style.css` — styling and responsive design
- `js/script.js` — smooth navigation and navbar interaction
- `images/` — place your profile/project images here

## Before publishing
Replace:
- `Your Name`
- `your.email@example.com`
- GitHub username
- LinkedIn profile
- Any project/skill information you want to change

## Run locally
Open `index.html` in VS Code and use **Live Server**.

## Publish with GitHub Pages
In the project folder:

```bash
git init
git add .
git commit -m "Initial commit: My portfolio website"
git branch -M main
git remote add origin https://github.com/YOURUSERNAME/YOURUSERNAME.github.io.git
git push -u origin main
```

Then enable GitHub Pages using the `main` branch and `/ (root)` folder.
